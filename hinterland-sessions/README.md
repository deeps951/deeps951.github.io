# The Hinterland Sessions

A fictional boutique music festival in the Gold Coast hinterland, designed as a five-page HTML/CSS-only portfolio concept.

## Pages
- `index.html` — Home
- `artists.html` — Artist lineup and profiles
- `timetable.html` — Saturday and Sunday schedule
- `experience.html` — Food, local markets, setting and native HTML FAQ
- `tickets.html` — Demonstration pricing cards (no transactions)

## Run locally
Open `index.html` directly in a browser. No server, installation, or build step is required.

## Fonts
The `head` of each page loads **Playfair Display** and **Inter** from Google Fonts. Visitors do not need these fonts installed. If Google is unavailable, Georgia/Arial fallbacks render immediately.

## Images
Local `.webp` files are original AI-generated concept imagery adapted into standalone assets for this site. The large sunset stage illustration and mountain logo are original SVG assets. All performers are fictional.

## Hosting
Copy this whole folder into your GitHub Pages root. Keep image and stylesheet folders intact.

## Important
The festival, artists, venue particulars, times, prices and passes are fictional demonstrations, not offers to sell real tickets. No personal information is collected.
