THE HINTERLAND SESSIONS — COMPLETE GITHUB PAGES WEBSITE
=====================================================

THE MAIN WEBSITE
----------------
The folder `hinterland-sessions/` is the finished five-page website.
Open `hinterland-sessions/index.html` in your browser to preview locally.

PUBLISH TO YOUR EXISTING GITHUB PAGES REPOSITORY
------------------------------------------------
1. Unzip this download on your Mac.
2. Open your LOCAL `deeps951.github.io` repository folder in Finder.
3. Copy the COMPLETE `hinterland-sessions/` folder into the repository root,
   alongside `livingcolour/` and `cafe-website/`.
4. Do not copy only the individual HTML files; KEEP the assets folder inside.
5. Review the files in GitHub Desktop, commit, and Push origin.
6. Test https://deeps951.github.io/hinterland-sessions/index.html

ADD A THIRD CARD TO YOUR EXISTING PORTFOLIO (OPTIONAL)
------------------------------------------------------
The `optional-portfolio-update/` folder contains a prepared homepage with
three cards, updated 3-column CSS, and a cover image for the new project.
If you have made newer edits to your live portfolio since the supplied
index.html, DO NOT blindly replace those files; manually merge the third card.

For the optional prebuilt integration, copy these THREE files to the matching
locations inside your existing repository:
  optional-portfolio-update/index.html -> index.html
  optional-portfolio-update/assets/css/main.css -> assets/css/main.css
  optional-portfolio-update/assets/images/hinterland-sessions-cover.webp
      -> assets/images/hinterland-sessions-cover.webp

The prepared homepage uses the CORRECT cafe-website/index.html path and
links to the festival at hinterland-sessions/index.html.

TECHNOLOGY
----------
HTML5 + CSS3 only. No JavaScript, backend, frameworks or build tools.
Google Fonts: Playfair Display + Inter, loaded with `display=swap`.
Fallbacks: Georgia and Arial. All other images/graphics are LOCAL assets.

SCOPE / ACCURACY
----------------
Fictional 2027 festival. All artists, lineups, prices and timings are invented.
The page shows demonstration ticket passes, NOT a working checkout.
The generated musician/experience images are illustrative, not real performers.

WHAT WE TESTED
--------------
All local HTML and image references, relative navigation targets and essential
page structure were checked. Full automated visual browser testing was blocked
in this environment; please check the desktop and phone layout locally.
